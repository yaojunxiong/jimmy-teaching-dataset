# Jimmy Teaching Dataset

## Goal

Build a structured teaching dataset containing 50 lessons that follow the Jimmy Teaching Standard.

## Folder structure

```text
.
├── README.md
├── roadmap.md
├── progress.json
├── docs/
│   └── Jimmy-Teaching-Standard.md
└── lessons/
```

- `docs/` contains the teaching standard and supporting documentation.
- `lessons/` contains the lesson datasets as they are developed.
- `roadmap.md` divides the 50-lesson target into delivery phases.
- `progress.json` provides machine-readable project progress.
